# 🚀 YouTube Auto Chapter Generator

Automatically generate YouTube chapters using AI.

## 🔥 Features
- Fetch YouTube video transcript
- Generate chapters using Groq LLM
- Format timestamps automatically
- Update video description

## 🛠 Tech Stack
- n8n (workflow automation)
- Groq API (LLM)
- YouTube API

## ⚡ How to Use
1. Import workflow.json into n8n
2. Add API credentials
3. Paste YouTube link in chat
4. Get auto-generated chapters
